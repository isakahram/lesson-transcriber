# Транскрипция урока

Простая программа для Windows: записывает онлайн-урок (звук из Zoom/браузера
и ваш микрофон) и превращает его в текст — файл `.txt` на рабочем столе.

* Никаких API-ключей, регистраций и облачных сервисов — всё работает на вашем компьютере.
* Всё бесплатно. Интернет нужен только для установки программы и один раз для
  скачивания модели распознавания речи.
* Интерфейс — одно окно с двумя кнопками: **«Начать запись»** и **«Остановить»**.

Пример результата — файл `Занятие 2026-10-13.txt` на рабочем столе:

```
Здравствуйте, давайте проверим домашнее задание. Как у вас дела с задачами из прошлого урока?

Первые три получились, а четвёртую я не смогла решить.

Хорошо, давайте разберём четвёртую задачу...
```

## 1. Что понадобится

| Что нужно | Подробности |
|---|---|
| Компьютер с Windows | Windows 10 или Windows 11 |
| Python | Версия 3.10, 3.11 или 3.12 (какую выбрать — написано ниже) |
| Микрофон | Можно встроенный в ноутбук, можно гарнитуру |
| Интернет | Нужен для установки библиотек и один раз для скачивания модели (~500 МБ) |
| Свободное место | Примерно 3 ГБ на диске `C:` |
| Время | Первая настройка — около 15 минут |

Опыт программирования не нужен: все команды нужно просто скопировать и вставить.

> **Важно.** Микрофон и системный звук записываются в двух отдельных потоках.
> Программа не требует установки драйверов — используется встроенный в Windows
> режим записи звука «WASAPI Loopback».

## Шаг 1. Установите Python

1. Откройте сайт **https://www.python.org/downloads/windows/**
2. Скачайте установщик **Windows installer (64-bit)**. Лучше выбрать версию
   **3.11** или **3.12** — с ними все библиотеки ставятся без проблем.
   Версия 3.13 и новее тоже работает, но под неё не всегда есть готовые сборки
   библиотек, и установка может занять больше времени.
3. Запустите скачанный файл.
4. **Самое главное:** в первом окне установщика поставьте галочку
   **«Add python.exe to PATH»** (внизу окна), иначе Windows не будет знать,
   где находится Python.
5. Нажмите **«Install Now»** и дождитесь окончания установки.

Проверка: нажмите `Win + R`, наберите `cmd` и нажмите Enter. В чёрном окне
наберите:

```bat
python --version
```

Должно появиться что-то вроде `Python 3.12.7`. Если появилась ошибка
«python не является внутренней или внешней командой» — значит галочка
«Add python.exe to PATH» не была поставлена. Переустановите Python
по шагам выше (галочку можно поставить только в установщике).

## Шаг 2. Скачайте программу

1. На странице проекта нажмите зелёную кнопку **Code → Download ZIP**.
2. Найдите скачанный архив (обычно в папке «Загрузки»), нажмите правой
   кнопкой мыши → **«Извлечь всё...»**.
3. Перенесите получившуюся папку в удобное место, например на рабочий стол.
   В папке должны лежать три файла: `main.py`, `requirements.txt`, `README.md`.

> Не запускайте программу прямо из архива — из архива она не работает.
> Файлы должны лежать в обычной папке.

## Шаг 3. Установите зависимости (одна команда)

1. Откройте папку с программой в Проводнике.
2. Щёлкните по **адресной строке** Проводника (там, где путь к папке),
   сотрите путь, напишите `cmd` и нажмите Enter.
   Откроется чёрное окно командной строки **уже в нужной папке**.
3. Скопируйте и вставьте эту команду (правый щелчок мышью вставляет текст),
   затем нажмите Enter:

```bat
pip install -r requirements.txt
```

4. Начнётся скачивание библиотек — это займёт от 3 до 10 минут. В конце
   должно появиться сообщение `Successfully installed ...`.

Если `pip` не найден — попробуйте ту же команду в таком виде:

```bat
python -m pip install -r requirements.txt
```

Если при установке видите слово `error` — посмотрите раздел
[«Если что-то не работает»](#если-что-то-не-работает).

## Как пользоваться

1. Начните урок в Zoom (или откройте браузер) — так, как вы всегда это делаете.
2. Нажмите **«Начать запись»**. Программа проверит микрофон и системный звук
   и начнёт запись. В строке состояния появится `Идёт запись... 00:00:12`
   с таймером.
3. Проведите урок как обычно. Свернуть окно программы можно — запись продолжится.
4. Когда урок закончился, нажмите **«Остановить»**.
5. Дождитесь надписи **«Транскрипция готова: ...»** и нажмите «ОК».
6. Откройте готовый файл на рабочем столе.

Кнопка **«Остановить»** становится активной только во время записи — так
случайно нажать её раньше времени не получится.

## Где искать готовый текст

Файл сохраняется на **рабочий стол**:

```
C:\Users\<Ваше имя>\Desktop\Занятие 2026-10-13.txt
```

* Имя файла — `Занятие ГГГГ-ММ-ДД.txt` (дата — день урока).
* Кодировка — UTF-8 (файл нормально открывается Блокнотом, Word и любым
  редактором).
* Внутри — только чистый текст: без таймкодов и служебных пометок. Паузы
  между фразами становятся абзацами.
* Если файл с таким именем уже есть, новый не перезапишется: программа
  добавит номер — `Занятие 2026-10-13 (2).txt`.

## Что происходит при первом запуске

При первом нажатии «Остановить» программа скачает модель распознавания речи
(около 500 МБ, это занимает несколько минут). В строке состояния будет видно:

* `Скачивание модели (около 500 МБ, только в первый раз)...`
* `Загрузка модели...`
* `Обработка транскрипции...` — и полоса прогресса

Скачивание происходит только один раз. Дальше распознавание работает
**полностью без интернета**: модель уже лежит на компьютере
(в папке `C:\Users\<имя>\.cache\huggingface`).

## Если что-то не работает

### «python не является внутренней или внешней командой»

Python не добавлен в PATH. Переустановите Python из установщика с python.org
и обязательно поставьте галочку **«Add python.exe to PATH»**.

### «pip не является внутренней или внешней командой»

Используйте команду с `python -m`:

```bat
python -m pip install -r requirements.txt
```

### В консоли вместо русских букв «кракозябры»

Выполните в том же окне:

```bat
chcp 65001
```

и запустите программу снова. На текст в готовом файле это никак не влияет —
файл всегда сохраняется в правильной кодировке UTF-8.

### Установка библиотек падает с ошибкой и словом `error`

* Проверьте, что у вас **64-битная** версия Python. В командной строке:
  `python -c "import platform; print(platform.architecture())"` — должно быть
  `64bit`.
* Если установлена версия Python 3.13 или 3.14, поставьте Python 3.11 или 3.12
  (готовые сборки библиотек для самых новых версий появляются не сразу).
* Попробуйте обновить установщик пакетов:
  `python -m pip install --upgrade pip`, затем снова
  `pip install -r requirements.txt`.

### «Ошибка: не удалось начать запись» / не слышно системный звук

Смотрите следующий раздел.

### Распознавание идёт очень долго

* Это нормально: программа работает на процессоре. Примерно **1 минута
  распознавания на 2–4 минуты урока** на среднем ноутбуке.
* Во время распознавания лучше не запускать тяжёлые программы.
* Если хочется быстрее — уменьшите модель (см. [Настройки](#настройки-по-желанию)).
* Готовый текст никуда не пропадёт, даже если компьютер «задумался»:
  дождитесь надписи «Транскрипция готова».

### При первом запуске «Не удалось скачать модель»

Интернет нужен только один раз. Проверьте подключение и снова нажмите
«Начать запись». Если у вас корпоративная сеть или VPN, попробуйте отключить
VPN: скачивание идёт с сайта huggingface.co.

## Если системный звук не записывается

Программа сообщит: **«Не удалось начать захват системного звука»** и предложит
продолжить запись только с микрофоном. Проверьте по шагам:

1. **Устройство вывода по умолчанию.** Windows: `Параметры → Система → Звук`.
   Урок должен звучать в то устройство, которое выбрано как «Устройство вывода
   по умолчанию» (например, «Динамики» или «Наушники»).
2. **Bluetooth-наушники.** У некоторых Bluetooth-устройств Windows не умеет
   записывать звук в режиме loopback. Попробуйте проводные наушники или
   динамики ноутбука — системный звук сразу начнёт записываться.
3. **Драйверы звука.** Если в диспетчере устройств есть восклицательный знак
   у звуковой карты — обновите драйвер.
4. **Проверьте список устройств.** В командной строке в папке программы
   выполните:

   ```bat
   python -m pyaudiowpatch
   ```

   В списке должны быть устройства со словом **`[Loopback]`** в названии.
   Если таких нет — Windows не может записывать системный звук на этом
   устройстве вывода.

5. **Последний вариант — виртуальный кабель VB-Cable.** Это бесплатная
   программа, которая создаёт «виртуальные колонки». Она помогает, если
   встроенный способ не работает.

   Как это сделать (кратко):

   1. Скачайте и установите **VB-Cable** с сайта
      **https://vb-audio.com/Cable/** (после установки обязательно
      **перезагрузите компьютер**).
   2. В Windows: `Параметры → Система → Звук` → в разделе «Дополнительные
      параметры звука» выберите устройство вывода по умолчанию
      **CABLE Input (VB-Audio Virtual Cable)**.
   3. В Zoom (или в браузере при просмотре урока) тоже выберите устройство
      вывода звука **CABLE Input**.
   4. Чтобы вы сами слышали урок, в окне VB-Cable (или в настройках
      прослушивания Windows) включите прослушивание: `Параметры → Звук →
      Дополнительные параметры звука → Запись → CABLE Output → Свойства →
      Прослушивать с данного устройства` и выберите там свои настоящие
      наушники или динамики.
   5. Запустите программу «Транскрипция урока» — системный звук теперь
      записывается с виртуального кабеля.

   > Если после этих шагов вы не слышите урок — значит забыт пункт 4
   > (прослушивание). Всегда сначала проверяйте, что звук слышно.

### «Микрофон не найден»

1. Подключите микрофон или гарнитуру (проводную — Bluetooth иногда капризничает).
2. Windows: `Параметры → Конфиденциальность и защита → Микрофон` — включите
   «Доступ к микрофону» и «Разрешить приложениям доступ к микрофону».
3. Windows: `Параметры → Система → Звук` → «Устройство ввода» — выберите нужный
   микрофон. Скажите что-нибудь: индикатор громкости должен шевелиться.
4. Закройте программы, которые могут «занимать» микрофон (например, открытый
   Zoom, Skype, Discord), и запустите программу снова.

### Программа предупредила: «Одна из дорожек не записывается»

Значит, один из источников звука отключился во время урока (например,
выдернули наушники). Вторая дорожка продолжает записываться — можно просто
закончить урок и нажать «Остановить»: текст всё равно получится.

### «Запись пустая»

Программа записалась, но в ней не было звука. Проверьте, что:

* урок действительно звучал в колонках/наушниках (а не в отдельном
  Bluetooth-устройстве);
* микрофон не был на паузе (Mute);
* регуляторы громкости Windows не стоят на нуле.

## Настройки (по желанию)

Все настройки — в самом верху файла `main.py`. Менять их не обязательно,
но иногда полезно. Открыть файл можно обычным Блокнотом.

| Строка | Что делает |
|---|---|
| `MODEL_SIZE = "small"` | Размер модели. `"base"` — быстрее, но менее точно; `"medium"` — точнее, но заметно медленнее |
| `LANGUAGE = "ru"` | Язык урока. Для английского укажите `"en"`, для другого языка — его код |
| `BEAM_SIZE = 3` | Качество распознавания (больше — точнее и медленнее) |
| `SAMPLE_RATE = 16000` | Не меняйте: Whisper работает именно с 16 кГц |

Пример: для слабого ноутбука замените строку

```python
MODEL_SIZE = "small"
```

на

```python
MODEL_SIZE = "base"
```

После правки сохраните файл и запустите программу снова.

## Как распознать уже сохранённую запись

Если распознавание не получилось, программа предложит сохранить запись (`.wav`)
на рабочий стол. Распознать её позже можно так — в командной строке в папке
программы выполните:

```bat
python main.py "C:\Users\Ваше имя\Desktop\Занятие 2026-10-13 (аудио).wav"
```

Программа распознает этот файл (без записи с микрофона) и положит рядом
готовый `.txt`.

> Чтобы вставить путь к файлу: в Проводнике щёлкните файл правой кнопкой мыши,
> зажмите `Shift` и выберите «Копировать как путь», затем вставьте в консоль.

## Частые вопросы

**Нужен ли интернет во время урока?**
Нет. Интернет нужен только для установки программы и один раз — для скачивания
модели. Сама запись и распознавание работают офлайн.

**Куда попадают мои записи?**
Никуда: программа ничего никуда не отправляет. Звук обрабатывается на вашем
компьютере, промежуточные WAV-файлы лежат во временной папке Windows и
удаляются сразу после того, как текст сохранён.

**Можно ли записывать урок без микрофона (только звук ученика)?**
Да: если микрофон не найден, программа предложит записать только системный звук.

**Что если урок длится два часа?**
Всё в порядке: запись идёт сразу в файл (память не тратится), а распознавание
выполняется кусками по 5 минут с аккуратными границами по паузам.

**Файл `Занятие 2026-10-13.txt` уже есть — он перезапишется?**
Нет. Новый файл получит имя `Занятие 2026-10-13 (2).txt`.

**Как удалить программу?**
Просто удалите папку с файлами. Если хотите удалить и скачанную модель
(около 500 МБ), удалите папку `C:\Users\<имя>\.cache\huggingface`.

**Можно ли закрыть окно во время записи?**
Можно, но программа сначала переспросит — иначе урок останется без текста.

> **Памятка об этике.** Запись разговора и публикация его текста могут
> затрагивать права участников. Предупредите ученика (а если он школьник —
> родителей) о том, что урок записывается для ваших рабочих заметок, и
> не делитесь файлом с посторонними.

## Состав проекта

```
lesson-transcriber/
├── main.py           — вся программа (интерфейс, запись звука, распознавание)
├── requirements.txt  — список библиотек для установки
└── README.md         — эта инструкция
```

Что используется внутри:

* **tkinter** — окно программы (уже встроено в Python);
* **PyAudioWPatch** — запись системного звука через WASAPI Loopback;
* **soundcard** — запасной способ записи системного звука;
* **sounddevice** — запись микрофона (и ещё один запасной способ loopback-записи);
* **soundfile**, **numpy** — чтение/запись WAV-файлов и смешивание двух дорожек;
* **faster-whisper** (модель `small`, `compute_type="int8"`, `language="ru"`,
  `vad_filter=True`) — распознавание речи на процессоре.

Все библиотеки — с открытым исходным кодом и бесплатны.
